# AeroForge RC

A simple static storefront for AeroForge RC.

## Publish on GitHub Pages

1. Create a GitHub repository (for example `aeroforge-rc`).
2. Upload `index.html` and `style.css` (and this README if you want).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide your Pages URL.

## Before launch

- Replace `YOUR-EMAIL@example.com` in `index.html` with your real business email.
- Replace the placeholder products, prices, and descriptions with products you actually sell.
- The contact form is currently a demo and does not send messages. Connect it to a form service or your own backend before relying on it.
- The site intentionally does not contain a payment processor. Add a payment method only after setting up an account you're legally allowed to use.

## Files

- `index.html` — homepage/storefront
- `style.css` — responsive styling
