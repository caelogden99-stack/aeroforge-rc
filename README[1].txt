AeroForge RC WireDock V1 website update

Included:
- index.html
- style.css
- CNAME (aeroforgerc.com)
- README.txt

Product specifications shown on the website are taken from the WireDock prototype source:
- Overall: 70 x 25 x 9 mm
- Base: 3 mm
- Rails: five parallel rails, 2 mm thick, 6 mm above the base
- Channels: four open-ended lanes
- Intended use: stationary workbench wire organization only

Print settings shown are suggestions, not fixed properties of the model:
- PLA for initial bench testing
- 0.2 mm layer height
- 15–20% infill
- No supports if slicer preview is clean

Before uploading:
1. Replace REPLACE_WITH_YOUR_EMAIL in index.html with your contact email.
2. Upload index.html and style.css to the repository root, replacing the old versions.
3. Keep the existing CNAME file and ensure it still says aeroforgerc.com.
4. Commit to the branch configured under Settings > Pages.
5. Wait for deployment.

This static website does not accept payments. The product is explicitly marked as a prototype, not for sale.
