AEROFORGE RC WEBSITE UPDATE — WIREDOCK V1

This version keeps the original AeroForge RC website's dark background, orange accents, header, and overall visual style, and adds WireDock V1 as the first prototype product with its full specification list.

BEFORE PUBLISHING:
1. Open index.html and replace REPLACE_WITH_YOUR_EMAIL with an email address you can use.
2. Upload index.html, style.css, and CNAME to the root of your existing GitHub Pages repository. Keep the existing CNAME if it is already configured for your domain.
3. Commit the changes and wait for GitHub Pages to publish.

WireDock is described as a workbench accessory prototype, not a flight component, and is marked not for sale yet. The product art is a schematic illustration, not a photorealistic render of the STL.
